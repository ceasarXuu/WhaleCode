## Reviewer outputs

### Reviewer A: proof/security

Summary: not closed. The reviewer found that the implementation had useful artifacts but was still self-attesting.

Blocking findings:

- `audit-review.json` was auto-generated by the runner and therefore could satisfy the E3 gate without an independent review.
- Runner equivalence relied heavily on stdout markers; wrapper and entry hashes were not bound to actual files or Docker inspect artifacts.
- Source guard proof trusted the in-memory object and did not bind to actual agent/tool process read denial.
- Directional benefit could be overstated because `include_taskspace_better` did not require standard failure.

Missing tests:

- Fake marker logs without Docker inspect must fail.
- Wrapper/entry hash mismatch must fail.
- Forged `SourceGuard` object or proof must fail.
- Missing audit review must not become E3.
- Both-success `include_taskspace_better` must fail.

### Reviewer B: runner/audit

Summary: not closed. The reviewer focused on test validity and runner equivalence.

Blocking findings:

- Completed audit reviews were generated by the runner itself.
- Official/equivalent runner proof compared current files to current hashes and did not prove pinned source cleanliness.
- Runtime proof was marker-based and not bound to generated validator artifacts.
- Source isolation did not probe child process identities or Docker/WSL-relevant access paths.
- Terminal-Bench `/app` alias was not enabled for `terminal_bench_equivalent_docker_app`.

Missing tests:

- Dirty official checkout must fail.
- Missing audit review must stay candidate.
- Fake validation markers and wrapper/entry mismatch must fail.
- Adapter-to-runner `/app` alias integration must be covered.

## Main-agent responses

All blocking findings were accepted.

- Audit self-attestation removed: `run-taskspace-benchmark.ps1` no longer creates completed `audit-review.json`. It only writes `audit-review.suggested.json` and `audit-review.template.md`.
- Added explicit reviewer writer: `write-taskspace-audit-review.ps1` writes `audit-review.json` only when reviewer, decision, rationale, artifact hashes, and attestations are explicitly provided.
- Added two-stage finalization: `finalize-taskspace-e3-run.ps1` recomputes pair reports and aggregate after completed audit reviews exist.
- Runner proof strengthened: `terminal-bench-adapter.ps1` records pinned git blob ids, current blob ids, source SHA256, task dirty status, and the E3 proof rechecks them.
- Runtime proof strengthened: the validator writes `terminal-bench-runtime-manifest.json` and `terminal-bench-docker-inspect.json`; `e3-proof.ps1` verifies wrapper hash, entry hash, `/tests:ro`, `/app`, `/tbench-entry.sh:ro`, and `/app` workdir from those artifacts.
- Source guard strengthened: `source-guard.ps1` records current process, child PowerShell, and `cmd` read-denial probes; `e3-proof.ps1` reads and validates the proof JSON instead of trusting the in-memory object.
- Directional decision gate strengthened: `include_taskspace_better` now requires TaskSpace success and standard failure; `include_standard_better` requires the inverse; disagreement blocks E3.
- `/app` alias fixed: `workspace.ps1` now enables the alias for `terminal_bench_equivalent_docker_app`.
