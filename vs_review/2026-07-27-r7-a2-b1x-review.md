##### Summary

A2-B1X 尚未达到 implementation-complete。response preflight 和 Store CAS 路径已经存在，但生产执行链有一个
correctness blocker：较早 sibling 失败后，后续已声明 Tool 被跳过，其预先提交的 reservation 会永久保留。
此外，`spawn_agent` 仍在普通 Tool schema 和说明中暴露旧 TaskSpace `node_id/current main-held node` 语义，
所以“普通 Tool 零侵入”完成声明不成立。

Reviewer 未修改文件，也未运行测试。

##### Blocking Findings

- `B-A2B1X-001`：前序 sibling 失败会泄漏后续已提交 reservation。
  - Broken assumption: 所有在 `prepare_taskspace_response` 中提交的 reservation 最终都会获得 factual result 或显式 release。
  - Failure scenario: 一个 response 声明至少两个跨 segment sibling；第一项失败，后续项只收到 synthetic skipped output，Store reservation 不变。
  - Trigger condition: 任意前序 Tool failure 触发 `prior_failure`，且后面仍有尚未 dispatch 的 segment。
  - Impact: canonical Map 永久保留 `InFlight`，阻断 finish 或后续执行；restart 会保存错误事实。
  - Proof needed: 多 sibling 失败测试必须证明 skipped action 被记录并释放，且 restart 后无泄漏。
  - Evidence:
    - `core/src/tools/sequence.rs:224`：dispatch 前提交全部 prepared reservations。
    - `core/src/tools/sequence.rs:605`：skip 分支只构造 `skipped_responses`。
    - `core/src/tools/parallel.rs:138`：release/attribution 只在实际 bound dispatch 中发生。
    - `core/src/action_map/runtime/transactions.rs:121`：canonical release transaction。

- `B-A2B1X-002`：`spawn_agent` 仍携带旧 TaskSpace `node_id`，违反普通 Tool 零侵入合同。
  - Broken assumption: 所有非 `taskspace_control` 普通 Tool 均不理解 TaskSpace node 归属。
  - Failure scenario: Standard 和 TaskSpace 都看到 `spawn_agent.node_id` 及 current-main binding 指引，但生产 handler 的 `SpawnAgentArgs` 根本不解析该字段。
  - Trigger condition: Tool registry 暴露任一 `spawn_agent` v1/v2 schema。
  - Impact: Standard schema 污染、固定 input 成本、Agent 被过时且无效的使用说明误导，完成声明失真。
  - Proof needed: 删除 `spawn_agent` 的 TaskSpace 字段和说明，并由 registry invariant 证明普通 Tool 无 TaskSpace decoration。
  - Evidence:
    - `tools/src/agent_tool.rs:11`：旧 current-main binding 描述。
    - `tools/src/agent_tool.rs:527` 与 `:564`：v1/v2 schema 都插入 `node_id`。
    - `tools/src/agent_tool.rs:607` 与 `:689`：v1/v2 Tool description 要求直接携带 `node_id`。
    - `core/src/tools/handlers/multi_agents/spawn.rs:185`：实际 `SpawnAgentArgs` 无 `node_id`。
