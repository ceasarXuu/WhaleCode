# Problem

# Hypothesis

- H-001：当前宿主缺少 user namespace、bubblewrap loopback 或等价能力，导致完整包测试不能作为候选回归证据。
- H-002：0.147 已消除 U1 的 runner 兼容问题，剩余 snapshot 差异仅为官方发布流程的精确 `0.0.0 -> 0.147.0` 机械差异。
- H-003：0.147 仍存在可在能力匹配环境复现、且不能归因于发布机械差异的候选缺陷。
