## 1. 结论

A2-B1X 的生产原子切换已经落地，但 complete/accepted 结论已在 2026-07-27 对抗性审查后撤回。核心路径不再
通过 singleton current binding、main lease 或 rollout replay 推断动作归属；但是 skipped prepared action 的
reservation closure 存在缺口，且 `spawn_agent` 仍残留普通 Tool TaskSpace `node_id` schema 污染。

本阶段关闭的是工程接线门，不是产品晋升门。尚未执行 A2-C 四臂 live sample，因此不能用本结果推断请求数、
input token、缓存、耗时或任务成功率收益。

## 2. 已落地能力

| 领域 | 落地结果 |
|---|---|
| Canonical Map | Store 直接保存 Root、Work、Finish、edges、completion、block、reservation、result/evidence 和 revision 事实 |
| 状态模型 | `Waiting/Ready/InFlight/Blocked/Completed` 由事实派生；无持久化 `Open/current` |
| L4 Tool | `taskspace_control` 收敛为 `initialize_and_execute/execute/read_map/read_output_ref/finish_map` |
| 普通 Tool | schema、参数、handler、权限、sandbox 和原生结果不感知 TaskSpace `node_id` |
| Response preflight | 完整 response 中 manifest 与 sibling Tool 按数量、顺序、名称、node 和 revision 一次校验 |
| 原子性 | Map mutation 与每动作 reservation 先在同一 Store transaction 提交；失败零普通 Tool dispatch |
| 结果归属 | 每个原生结果按 Agent 声明的 `call_index/node_id/reservation_id` 记录，不读取 current binding |
| Projection | 空 Map 和事实 Map 均从 canonical Store 构造；不输出 current-node 语义 |
| 持久化 | restart 直接读取 canonical records，不通过 snapshot/rollout 重放重建 Map |
| 旧路径 | 删除 binding、旧 initialization、旧 control parser、singleton lease、sentinel 和 snapshot restore 生产路径 |

## 3. 反馈与日志

生产路径新增或固定以下结构化事件：

```text
taskspace_response_preflight_started
taskspace_response_preflight_rejected
taskspace_action_manifest_matched
taskspace_action_reservation_committed
taskspace_native_tool_dispatched
taskspace_native_tool_result_attributed
taskspace_native_tool_result_attribution_failed
taskspace_finish_committed
taskspace_finish_rejected
```

日志仅记录 Map、response、call、node、Tool、reservation、revision、结果和机械 reason code，不记录普通 Tool
完整参数、API Key 或其他 secret。Tool 业务失败保持原始结果，Runtime 不追加下一步建议或语义判断。

## 5. 残留审计

生产模块树、L2 协议和 production manifest 中不存在旧
`taskspace_binding/bind_node/current_binding/current_node_id/restore_snapshot/main lease` 行为路径。
搜索命中仅剩两类：

1. 验证旧字段不会再出现在 schema/result 中的负向断言；
2. 已从模块树断开、尚未删除的历史测试文件和 fixture。

第二类不参与生产编译，但会误导维护者，按计划由 A2-B3 与运行手册一起清理。协议 snapshot 中其他历史展示字段、
projection detail fold 和 subagent reservation/取消/超时专项属于 A2-B2，不在 B1X 中扩张处理。
