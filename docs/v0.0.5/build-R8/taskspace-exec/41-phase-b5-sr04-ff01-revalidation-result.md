## 3. Waiting 观察

R04 中 Agent 在父节点尚未显式完成时，分别尝试在 `fix` 和 `verify` 子节点执行工作。Runtime 两次都在副作用前拒绝，
返回目标节点、`waiting` 状态、未完成直接父节点和“整批零执行”。Agent 随后的一个请求先完成对应父节点，再执行子节点
工作并成功。

这验证了 WF-01 的反馈忠实性和 DAG 硬边界，没有证明 Agent 已不再误选 waiting 节点。I04 继续作为 Agent 行为问题观察，
不得通过 Runtime 自动完成父节点、自动选点或放宽依赖规则来消除请求数。
