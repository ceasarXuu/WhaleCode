## 5. 刻意不打包的内容

以下内容不进入 R1 外部审计包：

- `reviewer-only/private-oracle` 和 hidden/private oracle 源文件。
- materialized scenario 的完整 `/app` 工作区、Docker build cache、uv cache tarball。
- 大型或可再生成的 validator runtime 临时目录。
- 本地 `docs/testing/v0.0.4/testing/` 暂存目录本身；该目录只用于组包，已加入 `.gitignore`。

## 6. 审计入口

建议外部审计按以下顺序阅读：

1. `00-清单/外部审计R1资料清单.md`
2. `01-核心报告/taskspace-e3-v004-research-report.md`
3. `04-clean-e3-run/suite/suite-health.json`
4. `04-clean-e3-run/suite/suite-timing.json`
5. `04-clean-e3-run/samples/*/aggregate.json`
6. `04-clean-e3-run/samples/*/pairs/*/audit.json`

关键判断口径：

- 若出现 Docker、validator、path、disk、materialization、report/audit 异常，本次成绩无效。
- 本次 clean run 的 public validator 原始结果是 Standard 7/15、TaskSpace 8/15。
- 本次仍处于 `audit_required`，所以 solved/wrong 是原始 public validation 结果，不是人工审计后的最终 benchmark claim。
- 成本结论必须同时看 agent 耗时、validation 耗时、direct tokens、uncached input 和 graph health。
