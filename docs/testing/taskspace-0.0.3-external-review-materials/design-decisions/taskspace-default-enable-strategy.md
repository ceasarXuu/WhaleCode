# TaskSpace Default Enable Strategy

- Future direction: TaskSpace may become default, but 0.0.3 evidence does not justify default enablement yet.
- 0.0.3 mode: manually entered; no same-session exit path by design.
- Thin / standard / deep remains an open design option for 0.0.4+.
- Low-complexity overhead is measured but not treated as a hard blocker; medium/high-complexity success-rate gain is the target.
