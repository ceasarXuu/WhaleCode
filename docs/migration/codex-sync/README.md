# Codex Sync Logs

Each Codex upstream import or upgrade gets one dated sync log in this directory.

Required fields:

- previous Codex commit;
- new Codex commit;
- import method;
- adopted upstream features;
- disabled or rejected upstream features;
- patch queue conflicts;
- bridge changes;
- tests run;
- residual risks.
