## Runner 最终合同

1. 先执行 `cargo fetch`，再离线构建 CLI、`codex-code-mode-host`、`codex` 与 `test_stdio_server`；
2. 从 OpenAI Codex `rusty-v8-v150.4.0` release 下载 sandbox archive/binding，并按官方 checksum 校验；
3. 包测试清除 proxy 与 ambient `CODEX_SANDBOX_NETWORK_DISABLED`；
4. 包测试使用外置私有 TMP、`umask 0022` 和 runtime TMP Git ceiling，避免宿主 IPC 权限与父目录 Git 发现污染；
5. app-server 单独隔离 HOME，避免开发者个人技能改变测试夹具；core/TUI 保留真实 HOME，因为其路径语义测试以 HOME 为基准；
6. 保持上游候选源码与生产 vendor 不变。

同步脚本 40 项单测、`py_compile`、`git diff --check` 与 candidate manifest check 均通过。
