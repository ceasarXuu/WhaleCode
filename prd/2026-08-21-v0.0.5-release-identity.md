# PRD：WhaleCode v0.0.5 发布身份

- Status: Ready for implementation
- Created: 2026-08-21
- Updated: 2026-08-21
- Owner / requester: 项目维护者
- Source request: 准备 v0.0.5 发布，并确保 Codex substrate 0.149.0 不被登记为 WhaleCode 版本。
- Product Authority: Confirmed Product Decisions section

## Requester Review Summary

- Key decisions: WhaleCode 对外版本统一为 `v0.0.5`；Codex `0.149.0` 只表示 upstream substrate。
- Important exceptions: upstream 同步证据可以继续使用 `rust-v0.149.0`，但不得进入 Whale CLI、产品 tag、包版本或发布登记。
- Must-confirm before implementation: 发布渠道和实际发布时间仍未确认，不属于本轮发布准备授权。
- Status reason: 版本身份及防误登记要求已由请求者直接确认，足以实施离线发布门禁。

## 1. 背景与产品意图

当前 Rust workspace 和 `whale --version` 沿用了 Codex `0.149.0`，而 WhaleCode 当前产品里程碑是 `v0.0.5`。两个版本表达不同对象，继续复用同一登记值会让 CLI、Git tag、包和发布说明错误地把上游版本当作 Whale 版本。

## 2. 目标与成功标准

- Whale 对外版本面统一报告 `0.0.5`，产品 tag 使用 `v0.0.5`。
- upstream 元数据继续精确记录 Codex `0.149.0` / `rust-v0.149.0`。
- 发布前存在机械门禁，同时核对两套身份并拒绝交叉登记。
- 准备流程不创建 tag、不发布包、不触发真实模型运行。

## 3. 用户与使用场景

面向 WhaleCode 维护者、发布操作者和使用 `whale --version` 判断安装版本的用户。

## 4. 范围

### In Scope

- Rust workspace/CLI 的 Whale semver。
- v0.0.5 机器可读发布登记、发布说明草稿和离线 preflight。
- Codex substrate 版本的独立校验。

### Out Of Scope

- 实际创建或推送 Git tag。
- GitHub Release、npm、WinGet、R2 或网站的实际发布。
- 改写 Codex upstream 资格证据中的 `rust-v0.149.0`。

## 5. 核心用户旅程

维护者更新 Whale 发布登记后运行 preflight；门禁分别读取 Whale workspace semver 与 Codex candidate 元数据。只有 Whale tag/version 一致、substrate tag/version 一致且两者没有混用时，才允许进入后续构建和人工发布审批。

## 6. 交互与信息设计

成功输出必须同时显示 `WhaleCode v0.0.5` 和 `Codex substrate rust-v0.149.0`。失败输出必须点名错误字段和期望值，不能只返回通用失败。

## 7. 产品规则与状态逻辑

- `preparing` 只代表准备中，不代表已发布。
- `publish_authorized=false` 时不得把登记文件当作实际发布授权。
- Whale 产品 tag 使用 `v<semver>`；`rust-v<semver>` 仅属于 Codex upstream。

## 8. 边界、错误与恢复

- Cargo 版本与发布登记不一致：preflight 失败，修正登记或 Cargo 后重试。
- Whale 与 substrate 版本相同或 tag 前缀混用：preflight 失败。
- candidate 元数据变化：必须先完成新的 upstream 同步资格流程，再更新 substrate 登记。

## 9. 内容与术语

- `WhaleCode v0.0.5`：产品发布版本。
- `Codex substrate 0.149.0`：当前上游底座版本。
- 不使用“Whale 0.149.0”或“Codex v0.0.5”。

## 10. 验收标准

- [ ] `whale --version` 输出 `whale 0.0.5`。
- [ ] `v0.0.5` 能通过 tag/version preflight，`rust-v0.149.0` 作为 Whale tag 会被拒绝。
- [ ] upstream candidate 仍通过 `rust-v0.149.0` 身份校验。
- [ ] preflight 和单元测试完全离线且不发起模型请求。
